Chapter 1. Context and role

One owner, no dedicated team

I owned AutoScout24's design system for three years, alongside full-time product work. There was no dedicated design systems team, in design or in engineering.

I designed and contributed many of the components myself. To scale beyond one person, I set up and ran a UI Guild that opened contribution to the wider design team. I stayed the final quality gate on every addition.

Chapter 2. The problem

Eleven modals

There were a handful of components, text styles and colours, with no system behind them. What Figma showed and what the codebase did were drifting further apart.

What the audit found

11 different modal styles live in production.

Then an acquisition in 2025 meant the system suddenly had to carry more than one brand.

Chapter 3. Foundations

Tokens that carry the brand

I audited the system and the product, finding components that were missing and components nobody used.

With engineering, I built a token naming convention. Engineering then wrote a script that imports tokens from Figma straight into the codebase. Because the tokens carry brand theming, designers and engineers can switch brand in one click.

I documented every component, and recruited the UX team to help.

Chapter 4. Governance

A bar everyone can see

The UI Guild gave the wider team a place to propose and discuss additions. Before anything was built, it went through a recurring review with engineering. I held the quality bar on every contribution.

Most recently, I integrated Figma Code Connect with MCP to automate AI-assisted design-to-code handoff.

Chapter 5. Impact

One system, every surface

60+components
30+repositories using it

Showcar is foundational to search, the private seller web flow and every key dealer interface. Designers and engineers work from the same CSS variables, so implementation is faster and more accurate.

Multi-brand support had to land before any product work on the acquired brands could start.

Chapter 6. Next

AI agents are becoming a customer for the design system.

Next is unlocking the system in Figma Make and Codex, and building workflows for designers to contribute directly to the codebase. Documentation is being adapted so agents can read it and implement to the same standard as the design team.
